Claim Detail Items

Each claim's details are stored as an array of individual detail items rather than a single text string. This enables per-item evidence, fact-checks, and human review feedback.

Database Schema

The claim_detail_items table stores individual detail bullets. Each item links back to a claim and has its own order position.

CREATE TABLE claim_detail_items (
    detail_item_id  SERIAL PRIMARY KEY,
    claim_id        INT NOT NULL REFERENCES claims(claim_id) ON DELETE CASCADE,
    item_order      INT NOT NULL,          -- 0-indexed position
    item_text       TEXT NOT NULL,         -- the detail bullet text
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Data Model

Detail items are produced by the LLM as an array of strings (2-4 per vendor), then stored as individual rows. Evidence and fact-checks link to specific items via detail_item_id.

// LLM output (array of strings)
"databricks_details": [
  "Serverless warehouses with 2-6 second cold starts, DBU-based billing.",
  "Photon C++ engine with SIMD delivers 2-8x performance.",
  "Delta Sharing open protocol adopted by 4,000+ enterprises."
]

// Stored as individual rows in claim_detail_items
// detail_item_id=42, claim_id=10, item_order=0, item_text="Serverless warehouses..."
// detail_item_id=43, claim_id=10, item_order=1, item_text="Photon C++ engine..."
// detail_item_id=44, claim_id=10, item_order=2, item_text="Delta Sharing..."

// Frontend receives structured detail items
"databricks_detail_items": [
  { "detail_item_id": 42, "item_order": 0, "text": "Serverless warehouses..." },
  { "detail_item_id": 43, "item_order": 1, "text": "Photon C++ engine..." },
  { "detail_item_id": 44, "item_order": 2, "text": "Delta Sharing..." }
]

Per-Item Citations

Citations use detail_item_index (0-based) to link to specific items in the details array. Evidence rows in the database use detail_item_id as a foreign key.

"citations": {
  "databricks_details": [
    {
      "citation_id": "cite_databricks_details_0_1",
      "detail_item_index": 0,          // links to 1st item in details array
      "start_index": 0,
      "end_index": 22,
      "source_index": 1,
      "source_quote": "Serverless SQL warehouses start in 2-6 seconds...",
      "verdict": "verified",
      "confidence": 0.92

    {
      "citation_id": "cite_databricks_details_1_1",
      "detail_item_index": 1,          // links to 2nd item in details array

      "source_index": 2,

Legacy claims without detail items fall back to a single-item list wrapping the original description field.

]

// Flat string still available for backward compat:
"databricks_details": "Original description text..."

Citations with Text Index Ranges

Every text field in the battlecard can have inline citations that map exact character ranges to source documents. This enables highlighting which part of the text is backed by which source.

Citation Object Schema

Each citation maps a character range [start_index, end_index) in the parent text to a source document.

{
  "start_index": 0,           // Start character offset (inclusive)
  "end_index": 13,             // End character offset (exclusive)
  "source_index": 1,           // Citation number for display [1], [2], etc.
  "source_title": "Databricks Unity Catalog Documentation",
  "source_url": "https://docs.databricks.com/...",
  "source_quote": "Unity Catalog is a unified governance solution for all data and AI assets"
}

How It Works

Citations are organized per-field in a citations object at the same level as the text fields they annotate.

// Example: text field with 2 citations
"databricks_details": "Unity Catalog provides centralized access control across all assets with ANSI SQL permissions",
                         |<-- [0,13) -->|                                            |<-- [65,87) -->|

"citations": {
  "databricks_details": [                    // Field name matches the text field
    {
      "start_index": 0,   "end_index": 13,    // "Unity Catalog"
      "source_index": 1,
      "source_title": "Unity Catalog Docs",
      "source_url": "https://docs.databricks.com/...",
      "source_quote": "Unity Catalog is a unified governance..."
    },
    {
      "start_index": 65,  "end_index": 87,    // "ANSI SQL permissions"
      "source_index": 2,
      "source_title": "UC Privileges Guide",
      "source_url": "https://docs.databricks.com/...",
      "source_quote": "GRANT/REVOKE syntax for privileges"
    }
  ]
}

Cited text ranges are rendered with blue highlights, superscript citation numbers, and hover tooltips showing the source.

How Grouping Works

Citations are filtered by detail_item_id so each evidence block only shows sources relevant to that specific detail item.

// JavaScript: group citations by detail_item_id
detailItems.forEach(function(item) {
    var itemCitations = allCitations.filter(function(c) {
        return c.detail_item_id === item.detail_item_id;
    });

    // Legacy fallback: if no match and single item, show all
    if (itemCitations.length === 0
        && item.detail_item_id === null
        && detailItems.length === 1) {
        itemCitations = allCitations;
    }

    renderEvidenceBlock(item.text, itemCitations);
});
